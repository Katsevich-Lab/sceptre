Fit reuse, plan snapshots and result history
Upstream changes make previous results historical. Response fits depend on data, actual design, ordered fitting cells and fitter version; high-MOI assignment changes can preserve them. The perturbation cache additionally depends on actual guide treatment assignments. Calibration bypasses that perturbation cache; CRT draws stay fresh, and shared non-targeting controls are not duplicated. Group-specific non-targeting discovery response fits need not be saved. RunPlan is temporary during execution and saved as a frozen snapshot with the result.
