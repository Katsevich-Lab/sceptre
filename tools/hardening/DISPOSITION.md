# Book-audit hardening disposition

Audit authority is the complete synthesized audit, extension assessment and both
independent full-book readers' reports at the frozen cef47da5 baseline. Those
read-only audit assets are unchanged. Implementation began at cef47da5; the
functional, mechanical-format and collector-review commits are distinct.
[Qualification receipts](QUALIFICATION.md) identify the final tested artifact.

| Recommendation | Disposition and evidence |
|---|---|
| 1. Own result graphs at admission and extraction | Implemented in `R/owned_results.R`, `commit_result_record()`, legacy admission and `get_result()`. A serialization roundtrip owns nested tables/S4/attributes without rewriting existing plan certificates. Tests mutate current/historical tables, nested attributes, RunPlan pairs and caller proposals, including old saved list plans; verify earlier/later objects and currentness. Eager deep-copy/repair approaches were rejected after meaningful R4.4 representation failures. No count-screen copying or result-output-hash substitute. |
| 2. Restore export sinks on every exit | Implemented scoped `write_analysis_summary()` with immediate connection/sink cleanup. Real public backed save → closed readRDS → failed export, successful public export with caller sinks, and original error/interrupt conditions are exercised. Output/message sinks are read back; fixture cleanup is defensive. |
| 3. Safe generated formulas | Construct symbols/calls in `baseenv()`, retaining selected covariates, order and log-zero policy. Literal dot-special names use constructed lookup calls. Actual offset calls are distinguished from variable names containing offset. Tests cover unusual names, both log branches, exact ordinary designs/contrasts/RNG and caller-local formula environments. Existing formula/design/result identities are not re-signed. |
| 4. Semantic correction settings | One errors helper serves early setters, initialized AnalysisSpec validity and saved schema-three admission. Untouched empty prototypes remain valid. Policy is one finite numeric `0 < alpha <= 1`; supported exact/unique partial p.adjust names and aliases retain supplied spelling. Saved corruption fails before execution/fitting. Three private manually constructed test fixtures now explicitly supply valid correction defaults; no assertions were removed. |
| 5. Honest testthat floor | API/argument inventory, genuine archived installations and actual full suites determine the floor. 3.1.7 was necessary but insufficient: it cannot mock the inherited print binding used by sink-condition tests; upstream 3.1.8 adds this capability. No sink coverage was weakened. Final floor/version/runtime receipts live in `dependencies/`. |
| 6. Permanent architecture and user contracts | Root ARCHITECTURE and package-owned module map now describe actual component ownership, reflected fields, RunPlan/FitCache, mutation/currentness, resource/condition and extension contracts. Saved-object help explains closed inspection, reopen, relocation, immutable backing and reimport; optional examples are guarded and genuinely tested without ondisc. NEWS includes visible fixes and the intentional calibration-budget correction. Old pipeline audits remain historical; current adapter qualification belongs to its separate worker. External illustration files were untouched. |
| 7. Structured worker diagnostics | Base `sceptre_worker_error` carries block, available analysis/phase, reason and original cause/parent. Serial/fork paths preserve useful messages, legitimate NULL and child-loss distinctions. Interrupts are re-signalled unchanged; failed workers cannot commit partial results/caches. Actual mixture/association callers supply context. |
| 8. Small consolidation and extension seams | Exact persisted fitter tags and canonical analysis names now have single helpers, with unchanged values. Contracts explain fitting, tests, storage and execution obligations without a universal registry. After explicit scope expansion, protocol1 implements the concrete needed prepare/whole-key work/collect boundary. It freezes global families/budgets/draw dimensions, uses process-local resources, checks actual R/schema/S4/native implementations and compact scope digests, and integrates/adjusts once. Fresh memory/backed workers and adversarial collection tests qualify the bounded local seam. |
| 9. Optional ondisc boundary | Lazy capability/shape/native-arity checks fail before backed file/native work; memory paths remain independent. Count/order/stored-zero/sentinel/shared-ID/native ownership semantics remain unchanged. Official source/release inspection found no supported public replacement for required private operations/shared-ID constructor. That upstream support/distribution gap remains external; no release/API support was invented. See ONDISC_CONTRACT for source pin versus separately installed version and limits. |
| 10. Support and performance qualification | Existing OS/ondisc-free CI retained; R-devel and explicit R-floor/Bioc release/devel gates added. Genuine local R4.4 and containerized native Linuxarm64 R4.1 qualification use isolated libraries, never the ordinary library. Exact statuses and unexecuted hosted/other-platform limits are in QUALIFICATION/dependencies. Bounded copy/cache benchmark records real fixture sizes, actual fit calls, latency/allocation limits and noise; no large-screen speed or peak-memory claim. |

The optional closure-hygiene suggestion is implemented with `force(index)` and a
rebinding regression. Wholesale explicit-prototype style changes, class hierarchy
expansion, blind optimization, backend replacement, a universal model registry,
and coverage-percentage targets were not warranted by a demonstrated requirement.
The semantic distinction between an empty constructor prototype and an initialized
scientific specification is explicit and tested. Native statistical algorithms,
RNG/draw ordering, full-budget generation and supported backend matrix are retained.
